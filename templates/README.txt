เทมเพลตของทีม (ทุกเครื่องเห็นในเมนู 📋 เทมเพลต และหน้าเริ่มต้น)

วิธีเพิ่มเทมเพลต:
1. ในเว็บ: จัดแผนให้เรียบร้อย → 📋 เทมเพลต → ＋ บันทึกแผนนี้เป็นเทมเพลต
2. กดปุ่ม ⬆ ข้างชื่อเทมเพลตนั้น (Export เทมเพลต) → ได้ไฟล์ .json
   (หรือใช้ไฟล์แผนจากปุ่ม ↑ Export → ไฟล์แผน .json ก็ได้)
3. เอาไฟล์มาวางในโฟลเดอร์นี้ (templates/) แล้วเปลี่ยนชื่อเป็น
   template1.json, template2.json, template3.json ... (ตัวพิมพ์เล็ก เลขเรียงติดกัน ห้ามข้ามเลข)
4. git add templates  ->  git commit  ->  git push

- เลขต้องเรียงติดกัน: ถ้ามี template1 กับ template3 แต่ไม่มี template2 → template3 จะไม่ขึ้น
- จะลบเทมเพลต: ลบไฟล์ แล้วเปลี่ยนชื่อไฟล์ที่เหลือให้เลขเรียงติดกันเหมือนเดิม แล้ว push
- จะแก้เทมเพลต: เอาไฟล์ใหม่มาวางทับชื่อเดิม แล้ว push
- ต้องเปิดเว็บผ่าน Vercel (หรือ Live Server ใน VS Code) — ถ้าดับเบิลคลิกเปิด index.html ตรง ๆ
  เบราว์เซอร์จะไม่ยอมให้อ่านโฟลเดอร์นี้ (เทมเพลตจากโฟลเดอร์จะไม่ขึ้น)
