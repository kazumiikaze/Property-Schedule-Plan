ชุดสำเร็จของทีม (ทุกเครื่องเห็นในแผง ⭐ ชุดสำเร็จ)

วิธีเพิ่มชุดของทีม:
1. ในเว็บ: ลากคลุม object ที่ต้องการ → ⭐ ชุดสำเร็จ ▾ → ＋ บันทึกที่เลือกเป็นชุด
2. ในแผงเดียวกัน กด ⬆ Export → ได้ไฟล์ .json (มีชุดของฉันทั้งหมดในไฟล์เดียว)
3. เอาไฟล์มาวางในโฟลเดอร์นี้ (presets/) แล้วเปลี่ยนชื่อเป็น
   preset1.json, preset2.json, preset3.json ... (ตัวพิมพ์เล็ก เลขเรียงติดกัน ห้ามข้ามเลข)
4. git add presets  ->  git commit  ->  git push

- เลขต้องเรียงติดกัน: ถ้ามี preset1 กับ preset3 แต่ไม่มี preset2 → preset3 จะไม่ขึ้น
- ชุดของทีมขึ้นป้าย "ทีม" และลบจากแผงไม่ได้ จะลบให้ลบไฟล์แล้ว push
- ต้องเปิดเว็บผ่าน Vercel (หรือ Live Server ใน VS Code) — ดับเบิลคลิกเปิด index.html ตรง ๆ
  เบราว์เซอร์จะไม่ยอมให้อ่านโฟลเดอร์นี้ (ชุดของทีมจะไม่ขึ้น)
