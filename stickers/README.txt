ชุดสติ๊กเกอร์ของทีม (แสดงในแถบ 🏷 สติ๊กเกอร์ ทุกคนเห็นเหมือนกัน)

วิธีใส่รูป:
1. ตั้งชื่อไฟล์เป็น stickers1.png, stickers2.png ... stickers10.png
   (ตัวพิมพ์เล็กทั้งหมด นามสกุล .png)
2. วางไฟล์ไว้ในโฟลเดอร์นี้ (stickers/)
3. git add stickers  ->  git commit  ->  git push

- ไฟล์ไหนยังไม่มี จะไม่แสดงในแถบ (เว้นว่างได้)
- แนะนำ PNG พื้นใส ด้านยาวประมาณ 300-600 px
- สติ๊กเกอร์ของทีมลบจากแถบในเว็บไม่ได้ ต้องลบไฟล์ในโฟลเดอร์นี้แล้ว push
- อยากได้มากกว่า 10 รูป: แก้ TEAM_COUNT ใน stickers.js
